Standing waves on a string

A string held at both ends can only vibrate in certain shapes. Pick one, change the string, and listen.

The motion is slowed down so you can see it. The sound plays the real frequency.

Try this

  1. Go from n = 1 to n = 2. Count the nodes. How does the frequency change?
  2. Tick show the two travelling waves. Two waves going opposite ways add up to one that stands still.
  3. Press listen, then increase the tension. This is what tuning a guitar or a veena does.
  4. Halve the length. The note goes up by an octave: the frequency doubles. That's why frets work.
the physics ✎

A wave on a string travels at v = √(T/μ), where T is the tension and μ the mass per metre (here 1.2 g/m, a light steel string). When it reflects off the fixed ends, the outgoing and returning waves overlap.

y(x, t) = 2A sin(kx) cos(ωt)

Only some wavelengths fit with a node at each end: L = nλ/2. So the string can only ring at f = n·v/2L. The lowest, n = 1, is the fundamental; the rest are its harmonics, and together they give an instrument its sound.
